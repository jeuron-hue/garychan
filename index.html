Process chemistry toolbox

Eight tools in one page. Calculators for charging, solution prep, yield and mass balance, units and agitation scale-up; a chromatography impurity profile parser; and an offline 2D structure editor. Nothing to install and nothing to configure.

Open the toolbox →
Jump straight to a tool
Charge Amount Charge quantities from a ratio basis. wt/wt, mol/mol, vol/wt, wt/vol and vol/vol. Solution Prep Prepare from solid, dilute from stock, or solve a molarity relation with any three of four terms. Yield & Mass Balance Molar yield, mass balance across splits, or both. Mode is selected per block. Unit Converter Common chemistry and engineering units. The pressure converter live-syncs kgf/cm² gauge, mmHg absolute and hPa absolute. Agitation Scale-up Geometric scale-up of agitated vessels. Assumes similar vessel geometry between scales. Equation Builder Your own variables and equations. Results chain forward, so each result is available to later equations. Impurity Profile LC/GC peak table parser. Shimadzu LabSolutions ASCII and Agilent GC CSV, vendor auto-detected. RRT grouping, blank subtraction, spec flagging, CSV/TSV/XLSX export. Structure Editor Draw a 2D structure and copy it straight into Word or PowerPoint. The drawing engine ships inside the page, so it works with the network disconnected.
Works offline. The toolbox is a single HTML file. Save reflux.html and open it from your own machine and every tool keeps working, the structure editor included. Three libraries load from a CDN for the spreadsheet exports and the Equation Builder; without a network those two features go quiet and everything else carries on.
